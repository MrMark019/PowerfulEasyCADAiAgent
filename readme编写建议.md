增加一下配置教程：
先点击上方的ai agent，然后点击设置，配置api url api model api key，下方可以选择通过Open ai方式或者Anthropic方式调用。其中Anthropic调用方式和claude code通用，在api url后面加v1即可 例如：https://api.kimi.com/coding/v1。 如果未能成功对话，可以打开DebugMode查看对话报错原因。
配置完成之后点击OpenChat开始对话，若配置成功，则可以在对话界面看到
v0.4.4 | Model: kimi-for-coding | Provider: anthropic | API: https://api.kimi.com/coding/v1/messages 表示API被成功解析。
然后还要提示用户，在原理图界面选中元件提问能够得到更多关于元件类型的信息，在PCB界面选中元件提问可以知道更多关于封装的信息
